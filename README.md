# **Network Traffic Analysis**

A hands-on networking lab where I used Wireshark inside an Ubuntu VMware virtual machine to capture and analyze common network protocols.

## **What I Analyzed**

- **ICMP** - Echo requests/replies, TTL, sequence numbers, and response times
- **DNS** - A record queries, UDP port 53, and DNS responses
- **TCP** - Three-way handshake (SYN, SYN-ACK, ACK)
- **HTTP** - Unencrypted HTTP request/response traffic
- **TLS/HTTPS** - TLS 1.3 handshake, SNI, cipher suite negotiation, and encrypted application data

## **Tools**

- Wireshark
- Ubuntu Linux
- VMware Workstation
- curl
- nslookup

## **Captures**

The `captures` folder contains the Wireshark `.pcapng` files used for each analysis.

## **What I Learned**

This project helped me better understand how common network protocols actually look at the packet level instead of only learning them theoretically.
